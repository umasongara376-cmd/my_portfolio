# Personal Portfolio Website

A personal portfolio website built with HTML and CSS to introduce the portfolio owner, present skills, and provide links to a résumé and project work.

## Repository Structure

- `portfolio.html` — main portfolio page.
- `css/` — stylesheet assets.
- `image/` — image assets used by the site.
- `audio/` — audio assets, if referenced by the pages.
- `resume.html` and `resume.pdf` — résumé resources referenced by the portfolio when present.

## Run Locally

No build process is required for a static HTML/CSS site.

1. Clone or download the repository.
2. Keep the HTML file and its referenced asset folders in their existing relative locations.
3. Open `portfolio.html` in a browser. For local development, a simple editor preview or static local server can also be used.
4. Check all navigation links and ensure the résumé files and assets referenced by the page exist.

## Technologies

- HTML5
- CSS
- Browser-based rendering

## Customization

Update the page text, skill list, project links, résumé links, and styles to reflect current information. Replace placeholder external links with the correct professional profiles and verify that any public contact details are intentional.

## Deployment

Because this is a static site, it can be hosted on a static website service such as GitHub Pages after confirming the entry-point file and asset paths.
